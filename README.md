# JEJAK NUSANTARA
## 3D Historical Adventure Game
> *“Don't make history feel like homework. Make history feel like an adventure.”*
> *(Jangan jadikan sejarah seperti pekerjaan rumah. Jadikan sejarah sebagai sebuah petualangan seru.)*

**Jejak Nusantara** adalah game petualangan 3D (*third-person 3D exploration adventure*) bertema sejarah Indonesia. Pemain berperan sebagai petualang muda yang memegang artefak misterius **Chronicle Compass**, menjelajahi dunia 3D interaktif pada berbagai periode bersejarah Indonesia, bertemu tokoh bangsa, memecahkan teka-teki lingkungan, mengumpulkan relik tersembunyi, dan mengungkap cerita autentik masa lalu melalui pengalaman bermain langsung.

---

## 🧭 Konsep & Desain Permainan

- **3D Open-World Level Exploration**: Dunia 3D *stylized* yang hidup dengan vegetasi bambu berayun, aliran sungai Citarum, dermaga perahu sampan, pos jaga militer, dan rumah panggung tradisional.
- **Protagonis Petualang 3D**: Karakter petualang muda lengkap dengan topi fedora beraksen emas, tas selempang penjelajah, jaket petualang, dan Chronicle Compass bercahaya di genggaman tangan.
- **Kamera Third-Person Cerdas**: Kamera orbit halus yang mengikuti karakter dengan pegas fleksibel, rotasi bebas menggunakan mouse (klik & drag) atau kontrol sentuh di layar seluler.
- **Fisika & Gerakan Responsif**: Mendukung jalan santai (*Walk*), lari kencang (*Sprint*), melompat (*Jump*), dan deteksi tabrakan lingkungan (*Collision detection*).
- **NPC Interaktif 3D**: Tokoh sejarah dimodelkan dalam bentuk 3D *stylized* yang memiliki ekspresi, bayangan, indikator berlian melayang, dan dialog bercabang.
- **Mini-Game Interaktif**: Teka-teki sandi peti rahasia PETA (*Cipher Lock*), penyusunan kronologi peristiwa kemerdekaan (*Timeline Challenge*), dan pencocokan peran tokoh pejuang.
- **Pemberian Penghargaan & Koleksi**: Jurnal petualang, relik tersembunyi berputar di udara dengan cincin aura, bintang pencapaian (★★★), serta sistem XP & lencana detektif.
- **Web Audio API Sound Engine**: Efek suara sintetis prosedural untuk derap langkah (rumput/kayu/tanah), pantulan lompatan, denting kompas, petikan dialog, melodi ambient, dan *victory fanfare*.

## 🗺️ Dunia 01: Desa Rengasdengklok (16 Agustus 1945)

### 🌾 Lingkungan & Landmark 3D:
1. **Rumah Bersejarah Djiaw Kie Siong**:
   - Rumah panggung berdinding anyaman bambu dengan atap limasan tradisional Karawang.
   - Serambi depan tempat Ir. Soekarno dan Drs. Mohammad Hatta berdiskusi dengan para pemuda di bawah temaram lentera minyak.
2. **Pos Jaga & Menara Pengawas PETA**:
   - Menara pengintai kayu dengan Sang Saka Merah Putih berkibar tertiup angin.
   - Tumpukan barikade karung pasir (*sandbags*), truk dinas PETA, serta peti amunisi berkode sandi.
3. **Tepi Sungai Citarum & Dermaga Perahu**:
   - Aliran air sungai Citarum bergelombang riak dinamis dengan perahu sampan kayu tradisional yang menjadi jalur rahasia transportasi air.
4. **Bentang Alam Pedesaan**:
   - Petak-petak sawah terasering berundak, jajaran pagar kayu, semak bunga liar, dan pepohonan rimbun.

---

## 📜 5 Misi Petualangan Terhubung (Quests)

1. **Misi 1 — Panggilan Pos Penjagaan PETA**:
   - Datangi pos jaga dan melapor kepada **Shodanco Singgih**. Pelajari situasi genting setelah siaran kekalahan balatentara Jepang bocor.
2. **Misi 2 — Mencari Tas Dokumen Djiaw Kie Siong**:
   - Temukan tas kurir PETA yang terjatuh di sekitar dermaga tepian Kali Citarum untuk membantu sang pemilik rumah.
3. **Misi 3 — Misteri Peti Sandi Kompi PETA**:
   - Pecahkan teka-teki sandi tanggal keberangkatan rombongan (`1608`) untuk membuka pesan darurat dari markas Menteng 31.
4. **Misi 4 — Diplomasi di Serambi Rumah Bersejarah**:
   - Masuki halaman rumah panggung Djiaw Kie Siong, temui Bung Karno dan Bung Hatta di serambi, serta pahami argumen mendalam mengenai proklamasi tanpa campur tangan Gunseikanbu.
5. **Misi 5 — Garis Waktu & Jaminan Mr. Achmad Soebardjo**:
   - Susun kronologi peristiwa kemerdekaan dan saksikan kedatangan mobil diplomat Achmad Soebardjo yang menjaminkan nyawanya agar dwitunggal dibawa kembali ke Jakarta malam itu juga.

## 💎 6 Benda Bersejarah Tersembunyi (Collectibles)

Setiap benda bersejarah dimodelkan dalam bentuk 3D unik dengan efek berputar dan pendar cahaya misterius:
1. **Radio Gelap Pendudukan**: Bukti penyadapan siaran radio luar negeri mengenai pengeboman Hiroshima-Nagasaki dan penyerahan Jepang kepada Sekutu.
2. **Notula Rapat Menteng 31**: Risalah pertemuan mahasiswa kedokteran dan pemuda radikal yang menuntut kemerdekaan diproklamasikan atas kekuatan rakyat sendiri.
3. **Peta Operasi Rengasdengklok**: Rute evakuasi preventif rahasia PETA dari Jakarta melewati Klender, Bekasi, hingga tangsi Bojong Karawang.
4. **Koin Sen Masa Pendudukan**: Uang koin tembaga era militer Dai Nippon (2605 / 1945 M).
5. **Foto Bersejarah Serambi Bojong**: Potret dokumentasi ruang depan rumah petani Djiaw Kie Siong tempat dwitunggal beristirahat.
6. **Kantung Surat Kurir Pos PETA**: Dokumen komunikasi kurir pemuda pembawa kabar perkembangan situasi Jakarta.

## 🛠️ Instalasi & Menjalankan Game

### Prasyarat:
- [Node.js](https://nodejs.org/) (versi 18 ke atas)
- Browser modern dengan dukungan WebGL (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari)

### Langkah Menjalankan:
```bash
# 1. Masuk ke direktori proyek
cd d:\Historical_Detective

# 2. Pasang dependensi
npm install

# 3. Jalankan development server
npm run dev
```

Buka URL di peramban: `http://localhost:5173`

### Membangun Versi Produksi:
```bash
npm run build
npm run preview
```
